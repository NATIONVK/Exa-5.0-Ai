# Exa AI — NEXUS AI

NEXUS AI is an advanced personal-intelligence ecosystem planned for Android and Web.

## Product direction

- Autonomous task understanding, planning, and agent orchestration
- User-controlled long-term memory and knowledge retrieval
- Bangla and English text/voice interaction
- AI chat, research, coding assistance, and file analysis
- GitHub workflows and browser automation with explicit approval gates
- Cinematic cyberpunk / holographic interface

## Repository structure

- `docs/ROADMAP.md` — phased development plan
- `docs/CORE_AI_BRAIN_SPEC.md` — Phase 01 functional specification
- `docs/SECURITY.md` — security and autonomy requirements

## Current status

This repository currently contains the product specifications and development plan. It does **not** yet contain a completed or tested application implementation. Implementation should be added in small, testable phases.

## Important

Never commit API keys, passwords, tokens, private user data, or production secrets. Configure provider credentials through the deployment platform's secret/environment manager.
